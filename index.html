Visokio

2007 to present

From Omniscope Classic to Evo.

I began at Visokio on Omniscope Classic, the earlier desktop application, before moving on to its successor, Omniscope Evo. As a senior software engineer, I work with the team across Evo’s Java backend and JavaScript, CSS and React frontend. My responsibilities span AI authentication, cloud subscriptions, reporting automation and cross-platform releases.

AI authentication
I implemented OAuth 2.1 authentication for Omniscope’s MCP server, covering sign-in, endpoints and Admin screens. AI assistants operate within the person’s existing permissions and authorised folders.
Cloud & SaaS
I implemented Omniscope Cloud’s sign-up, sign-in, trial and subscription flows, integrating Auth0 and Stripe.
Identity & access
My Admin work covers sign-in, permissions, single sign-on and API-key configuration.
Automation & APIs
I develop Scheduler functionality across server and client, including automated execution and retries, alongside project automations, parameters and REST APIs.
Product experience
My work also covers data visualisation, report views, filtering, customer branding and licensing.
Release engineering
I maintain the build pipeline, code signing and release packaging, working with the team to deliver Windows, macOS, Linux, Docker and cloud releases.
Customer troubleshooting
I diagnose failures on customer servers, working with the team to identify causes and resolve issues.

Company code, internal designs and confidential details are not shared.
