More about my engineering responsibilities
AI authentication
I implemented OAuth 2.1 authentication for Omniscope’s MCP server, covering sign-in, endpoints and Admin screens. AI assistants operate within the person’s existing permissions and authorised folders.
Cloud & SaaS
I implemented Omniscope Cloud’s sign-up, sign-in, trial and subscription flows, integrating Auth0 and Stripe. I also help set up Omniscope’s public SaaS services.
Reporting & frameworks
I work on filtering, reporting and shared application frameworks, including persistence and saved explorations.
Identity & access
My Admin work covers sign-in, permissions, single sign-on and API-key configuration.
DevOps & infrastructure
I set up Docker containers and use Terraform to help manage infrastructure at Visokio. My work also includes cloud marketplace releases and operational runbooks.
Automation & APIs
I develop Scheduler functionality across server and client, including automated execution and retries, alongside project automations, parameters and REST APIs. I also work on schedule validation and project-level notifications.
Product experience
My work also covers data visualisation, report views, filtering, customer branding and licensing.
Release engineering
I maintain the build pipeline, code signing and release packaging, working with the team to deliver Windows, macOS, Linux, Docker and cloud releases. This includes work on Windows app-store packaging and user-data persistence.
Customer troubleshooting
I diagnose failures on customer servers, working with the team to identify causes and resolve issues.
